# FastAPI Basic App

## Project Description
This is my first FastAPI application, created as part of my Social Eagle AI course.

## Features
- Home API endpoint (`GET /`)
- About API endpoint (`GET /about`)
- Interactive API documentation (`/docs`)

## Technologies Used
- Python
- FastAPI
- Uvicorn

## Installation

Install the required packages:

```bash
pip install -r requirements.txt
```

## Run the Application

```bash
uvicorn main:app --reload
```

Open these URLs in your browser:

- Home: http://127.0.0.1:8000/
- About: http://127.0.0.1:8000/about
- API Documentation: http://127.0.0.1:8000/docs
